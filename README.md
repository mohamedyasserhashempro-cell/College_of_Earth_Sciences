# College_of_Earth_Sciences
A modern, responsive website concept for a College of Earth Sciences and
Mining. The visual direction is inspired by geology, mineral
exploration, and the mining industry, using a dark navy and gold color
palette.
Live Website

This project presents the college through a clean, contemporary web
interface designed to work across desktop and mobile screens.
Highlights
- Responsive layout for desktop, tablet, and mobile
- Geology- and mining-inspired visual identity
- Dark navy and gold color scheme
- Clear, user-friendly navigation
- Dedicated visual experience for different screen sizes
Project Information
- Project type: Frontend website / UI design
- Status: Live preview
- Source code: Not included in this repository
